How to use the outlook

The main number describes whether an issued NOAA HRRR forecast contains a combination of conditions favorable for a cloud layer over Boulder that may end before Green Mountain (8,133 ft), with relatively clear air above. A 75/100 does not mean a 75% probability.

Choose a time

Use the time slider, arrows or Play. Only hours actually downloaded appear. The cloud illustration updates from NOAA's low, middle and high cloud fractions. Its vertical shape is schematic. The dashed humidity drying altitude, when present, is not a measured cloud top.

Map and vertical humidity

The map compares ten named positions between Boulder and nearby foothills. All readings are numerical forecasts at the nearest HRRR model grid cell; sites very close together may share the same cell. Darker/more vivid humidity values do not guarantee fog or visibility at a hiking summit.

Forecast history

Inspect one weather hour from 24, 18, 12, 6 and 0 hours before it occurred. Later reconstructions are clearly identified. At-event T−0 is the latest plausibly available forecast, not observed conditions. The independent airport METAR card is separate.

Refresh and storage

Press Refresh forecast. The site gets the latest available HRRR run, fills selected historical vintages, and refreshes nearby airport observations. It reuses cached downloads. Large numerical GRIB subsets are discarded after extraction; short-term caches expire after seven days, while historical snapshots remain.

Run python -m scripts.storage status to inspect disk usage. Run python -m scripts.storage cleanup to preview eligible deletion, and append --apply to execute it.

Safety

Always consult updated NWS forecasts, webcams, and actual trail conditions before heading out. Scenic cloud-top clearance is not independently verified.
