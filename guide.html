Understanding the short-range tracker

The large gauge now displays a hand-weighted 0–100 ABOVE-THE-CLOUDS scenic suitability index for Green Mountain. It seeks low clouds over Boulder, dry air below and at Green Mountain (8,133 ft), and little middle/high cloud. The earlier low-cloud/inversion index is still shown alongside it. Both use an initialized HRRR forecast. It works before training models. The heuristic quicklook can display HRRR extended-run forecast leads through 48 hours from model initialization; trained ML outputs remain limited to their supported leads below 40 hours. Because model results are not distributed instantaneously, the remaining future window may be shorter than 40 hours.

Neither index is a probability or a measured inversion. The scenic index is also not a verified cloud-top altitude or a guarantee of sunshine. When a model is trained, a separate percentage gives an experimental probability of low ceilings or fog at Boulder Municipal Airport (KBDU).

Past 48 hours: forecast vintages and airport observations

Use Past 48 hours to compare T−24, T−18, T−12, T−6 and T−0 forecasts. T−0 is the latest HRRR run plausibly available at event time, not an observation. A separate KBDU METAR panel displays actual airport reports when refreshed. Each entry identifies its HRRR run and whether it was captured by the app at the time or reconstructed later from archived NOAA forecast runs. Reconstructed values are not evidence of what the page actually showed earlier. Forecast captures require a current, running HRRR download schedule; sleeping MacBooks cannot continuously collect forecasts.

Both 0–100 indices are subjective forecast rankings, not event probabilities; old saved scores are not retroactively recalculated after algorithm upgrades. A high value is not proof of a sea-of-clouds event.

Reading the heuristic index and ML probabilities

The large gauge shows the GREEN MOUNTAIN scenic index out of 100. It penalizes high/middle cloud and high cloud bases, and checks the coarse HRRR humidity profile for drying below and above the summit. The original low-cloud index uses low-level stability, moisture, HRRR low clouds, wind, modeled boundary-layer height and visibility; the full reading breakdown remains visible beside the scenic index. This score is not a probability. A separate ML card shows the average of XGBoost and a small CNN only after training on KBDU observations. The models receive numerical weather predictions of surface humidity, visibility, cloud cover, winds and vertical structure. Click a day or an hourly bar to inspect a specific forecast valid time. The chart switches among scenic index, low-cloud index and HRRR low-cloud coverage, none of which measures actual cloud-top heights.

Elevation-specific outlook

First Flatiron (7,258 ft) and Green Mountain (8,133 ft) each get a separate uncalibrated scenic index. The indices favor a low cloud deck that likely ends below the summit and no middle/high cloud above it. Each landmark also reports its position relative to HRRR generic modeled cloud-top height where available. A general cloud-top of 38,000 ft can belong to an upper cloud layer; it does not identify where Boulder fog ends. Vertical RH drying is only a proxy for low-deck depth, not an observed cloud-top height. Summit location may differ substantially from the KBDU model grid cell. Elevation-conditioned scenic training is not enabled without verified summit data. Otherwise it says Not trained. If enough reported low cloud bases exist, a separate regression model estimates the airport low-cloud base altitude, not the cloud-top or safe breakout elevation.

Do not use airport fog probability as a guarantee that Boulder is covered while Green Mountain is sunny. The diagram is schematic and does not indicate observed summit clearance.

Synthetic presets

Classic, high, socked and clear presets are illustrative examples only. Their numbers and cloud layers are invented to test the interface. The live mode never replaces a failed data request with a synthetic prediction. For new weather data, rerun `python -m inversion.hrrr live`; the browser reload reads the cached file.

For contributors

See the README for collecting independent airport METAR observations, retrieving issue-time-preserved HRRR runs, training the models, adding summit observations, and running the local FastAPI server. Current provider data may be sparse for rare fog cases. The model refuses to train when it cannot validate both classes.

Why this heuristic score?

The live dashboard now shows the actual model forecast readings, their six hand-chosen weights, each factor's points, and links to the original NOAA HRRR forecast inventories. A 96/100 score is a setup index, not a 96% inversion probability. The factor readings can be correlated because they all derive from the same forecast model. Historical snapshots captured after this explanation feature was added also preserve these readings; earlier snapshots do not contain them.

Sunrise, sunset and interactive cloud-layer explorer

The dashboard shows astronomical Boulder sunrise, sunset, civil twilight and approximate golden-hour timing. The calculation is local, requires no extra weather download, accounts for Mountain Time daylight saving, and assumes an unobstructed horizon. Rocky Mountain ridgelines can delay visible sunrise.

Use the big time slider or its previous/next/play controls to inspect real downloaded HRRR forecast hours. The cloud illustration is a schematic: low-cloud coverage changes its opacity, modeled middle/high cloud fractions change the upper sky, and the dashed line—when present—shows an RH-profile drying transition rather than a measured low-cloud top. Missing cloud-top evidence is displayed as unknown, not guessed. The full conditions grid shows winds, temperature, dew point, visibility, mixing-layer height, summit humidity, and neighboring-grid disagreement when available.

The target elevations are now First Flatiron 7,258 ft MSL and Green Mountain 8,133 ft MSL. Historical snapshots preserve the scenic algorithm version that originally produced them; newly reconstructed forecasts use the updated elevations.
