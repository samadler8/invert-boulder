# Archived machine-learning experiment

These files were intentionally moved out of the active app. They contain the earlier XGBoost/CNN training, prediction, and GFS experiments. They are retained for reference **but are not supported by the active dependencies or run path**. To restore the old pipeline, use the previous full repository ZIP or a Git commit; simply executing these files in their archived location may need import/path adjustments. No previous local `data/` or `models/` files are deleted by the overlay.
