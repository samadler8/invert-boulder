Three different physical events

Temperature inversion: locally warmer air above colder air; a vertically resolved thermal phenomenon. Airport fog: measured near-surface visibility and clouds at a weather station. Scenic cloud sea: low clouds in the Boulder area with clear viewing at a particular higher elevation. None is equivalent to the others.

Two independent hand-designed indices now use HRRR forecasts: (1) a low-cloud/inversion setup index, and (2) the main above-the-clouds scenic suitability index for Green Mountain and First Flatiron. Neither is observation-trained or a calibrated probability. When available, the separate airport low-ceiling/fog ML output is trained with independent METAR observations. It does not establish a measured inversion or above-cloud summit event.

Numerical weather forecasts become ML features

The NOAA HRRR archive contains individually initialized model runs that can be selectively accessed using Herbie. We ingest surface forecast humidity, visibility, clouds, forecast cloud-base/top heights and wind, plus atmospheric temperature, humidity, wind and geopotential height at five pressure levels. XGBoost also receives local time and forecast lead (hours between run initialization and valid time). The CNN receives four interpolated vertical channels: temperature, humidity, east-west and north-south wind.

All training and inference weather features come from a particular initialized HRRR forecast run. The strict lead-time bound is less than 40 hours. An issued forecast is not replaced with the hindsight-laden stitched historical forecast archive.

Heuristic now, ML later: different kinds of numbers

The ORIGINAL low-cloud setup index is a hand-selected, transparent combination of six HRRR forecast ingredients. Its weight fractions are 0.29 stability, 0.24 moisture, 0.20 modeled low-cloud coverage, 0.12 weak winds, 0.10 shallow boundary layer and 0.05 reduced visibility. Each factor is mapped to 0–100 and combined into a 0–100 ranking. Thresholds and weights are hypotheses, not calibrated probabilities. The SECOND, scenic index combines the first index with additional necessary factors: low cloud base near Boulder, lower-tropospheric RH drying before each target summit, low RH at and above the summit, and strong penalties for modeled middle/high cloud cover. Middle/high-cloud fractions now receive a smooth, strongly decreasing scenic penalty rather than a hard zero at 85%. This is a subjective scoring hypothesis, not a measured sky clarity probability. This is also a heuristic, NOT a calibrated probability or direct cloud-top measurement. Both indices run without trained ML weights.

Once trained, a separate XGBoost+CNN output estimates the probability of a specified observed airport low-ceiling/fog target. These numbers do NOT measure the same event and should not be treated as interchangeable. HRRR generic cloud-top height may refer to very high clouds, so it is not the low-fog cloud-top height. RH-profile drying is an approximation to a potentially shallow layer, not a verified cloud-top boundary, and one KBDU grid point cannot guarantee summit clearance.

Independent observations and labels

Airport KBDU/METAR visibility, `FG` weather reports and reported ceiling layers define the station fog target. Reports are retrieved independently from the Iowa Environmental Mesonet. Missing/ambiguous observations are not treated as clear conditions. A separate model may learn the altitude of the base of reported low BKN/OVC cloud at the airport, using its 5,288 ft MSL field elevation. Cloud top cannot be recovered from airport METAR data.

A future elevation-conditioned classifier could learn the joint airport-cloud-and-summit-clear event after independently verified mountain observations are collected. Such a classifier is not currently implemented or trained. With no such data, the website displays “Not trained” for independently validated scenic probabilities while still showing an explicitly uncalibrated scenic heuristic.

Training and uncertainty

Train/validation/test partitions are chronological by forecast valid time, with a 40-hour gap to reduce leakage from overlapping forecast runs. The low-ceiling/fog classifiers can be calibrated on validation events. Holdout Brier, log-loss, ROC AUC and average precision are reported; rare-event class balance and validation selection remain concerns.

A model with positive HRRR temperature gradients is only displaying a forecast inversion signal; there is no independent observed inversion training target yet. Keep the distinction visible in scientific interpretation.

Primary sources

NOAA HRRR · Herbie · IEM observed METAR. Full reproducibility instructions and caveats are in the repository README.

Historical forecast provenance

The forecast-history panel stores the original model-run timestamp, forecast valid timestamp, heuristic version and captured-at timestamp. To avoid hindsight bias, a captured forecast is only eligible for comparisons after it was saved. Archive backfills are explicitly labeled as retrospective reconstructions, with a two-hour assumed HRRR availability delay. Forecast inputs were issued earlier, but this does not prove that the site displayed those same values in the past.

Why this heuristic score?

The dashboard now shows both the original six-factor low-cloud calculation and the new scenic-factor diagnostics, including high/middle cloud fraction, modeled cloud base, RH near the summits, and an RH-based drying-transition height. Links identify the original NOAA HRRR forecast inventories. A 96/100 score is a setup index, not a 96% inversion probability. The factor readings can be correlated because they all derive from the same forecast model. Historical snapshots captured after this explanation feature was added also preserve these readings; earlier snapshots do not contain them.

Sunrise, sunset and interactive cloud-layer explorer

The dashboard shows astronomical Boulder sunrise, sunset, civil twilight and approximate golden-hour timing. The calculation is local, requires no extra weather download, accounts for Mountain Time daylight saving, and assumes an unobstructed horizon. Rocky Mountain ridgelines can delay visible sunrise.

Use the big time slider or its previous/next/play controls to inspect real downloaded HRRR forecast hours. The cloud illustration is a schematic: low-cloud coverage changes its opacity, modeled middle/high cloud fractions change the upper sky, and the dashed line—when present—shows an RH-profile drying transition rather than a measured low-cloud top. Missing cloud-top evidence is displayed as unknown, not guessed. The full conditions grid shows winds, temperature, dew point, visibility, mixing-layer height, summit humidity, and neighboring-grid disagreement when available.

The target elevations are now First Flatiron 7,258 ft MSL and Green Mountain 8,133 ft MSL. Historical snapshots preserve the scenic algorithm version that originally produced them; newly reconstructed forecasts use the updated elevations.
